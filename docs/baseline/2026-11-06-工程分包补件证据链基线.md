## 三、数据契约（已确认）

`BsMaterialFact` 已落地字段：

- 定位：`task_id`、`material_id`、`generation_id`、`page`、`field_path`、`quote`
- 值：`raw_value`、`normalized_value`、`confidence`
- 质量与来源：`quality`、`source_kind`
- 版本：`parse_batch_id`、`schema_version`、`extractor_version`、`content_sha256`、`material_version`

批次身份：`content_sha256[:32] + extractor_version`。同一内容与同一抽取器版本进入同一批次；内容或抽取器变化产生新批次。

白名单：

- `source_kind`：`online_ocr_text`、`local_ocr_text`、`embedded_text_layer`
- `quality`：`readable`、`review_required`、`unreadable`

已确认的四项契约决策：

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| D-1 | 事实写入事务点 | 在 `_finish_ingest` 内，材料解析成功字段赋值后、`material.parsed` 事件前，用同一 session 写入；抽取失败记录 `facts_failed` 降级并继续提交解析，事实可幂等重放 |
| D-2 | 失败页和质量可疑页 | 解析成功的质量可疑页可产生候选事实并标记 `review_required` / `unreadable`；解析失败的材料不生成事实；任何情况都不自动重跑 OCR |
| D-3 | 删除与保留 | 本阶段保留 `ON DELETE CASCADE`，任务删除视为用户授权的合法清除；永久审计留存另立变更 |
| D-4 | 并发幂等 | `page` 改为 `NOT NULL DEFAULT 0`（0 表示材料级/无页码），增加 `(material_id, parse_batch_id, field_path, page)` 唯一约束，并捕获 `IntegrityError` 视为重复 |

注意：D-4 是已确认但尚未在代码中实施；当前 `page` 仍可空且没有唯一约束，属于 S1 范围。
