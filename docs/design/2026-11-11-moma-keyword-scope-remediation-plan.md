- 固定规则完整可用材料范围、机器结论、人工处置及历史报告必须与 AI 输入选页保持独立。

## 推荐设计

在 `build_review_context` 和模型批处理之间设一个纯函数式范围选择模块。输入为当前已授权的可读页、finding 锚点、主体/材料归属、当前规则快照及读取完整性；输出为原输入页的子集、是否部分范围、证据类别命中、选择原因和限制。模块不读写数据库、不请求模型，也不修改 finding。

选择依据按规则的必需证据类别组织，而不是递归收集所有 `*_words` 后统一字面匹配。词项和模式应引用唯一规则定义；同一规则的“范围、主体、资金、签章”等类别各自映射到材料/页候选。只有命中页、必要锚点页和结构上相连的页进入候选。表格续页、跨页条款、附件关系要按现有材料结构保留；无法确定关联时回退。

以下情况回退到当前既有上下文，并保留其原有范围限制：无选择器、无可靠命中、候选为空、必要证据类别无法定位、主体/材料归属不明、OCR/解析质量不可靠、现有结构化证据已标出的冲突未纳入候选、选页执行异常。回退意味着“不应用新的筛选”，不代表材料完整或结论确定。选页器不能可靠发现未由既有结构化逻辑标出的任意语义冲突；这类残余风险仍需通过范围限制和后续人工核查管理。

选择命中但仍未覆盖全部可读资料时，继续设置现有 `incomplete_material_scope`，传递现有限制语句和验证护栏。部分输入不得产生确定符合/不符合或整包缺件结论。固定规则始终读取完整可用材料；AI 辅助建议、证据引用、人工采纳/忽略及报告结论彼此独立。

审计仅记录任务/运行/主体/材料 ID、选择器版本、页码、命中证据类别、候选与回退原因、范围标记及页数/用量等元数据，不记录材料正文、模型完整请求或凭据。检查点身份包含选择器版本及实际选页输入指纹，避免候选输入复用全量输入的结果。

## 多角色要求

| 角色 | 关注点 | 验收责任 |
| --- | --- | --- |
| 业务负责人 | 固定规则仍覆盖全量可用材料；AI 不形成新业务结论 | 确认规则证据类别映射、fallback 条件和默认开关 |
| 业务专家 | 事实是否保留、引用能否支撑、是否遗漏反例 | 后续审阅代表性基线/候选结果；未审阅前不签业务准确性 |
| AI/后端 | 输入边界、归属隔离、限制传递和检查点一致性 | 纯选择模块、受控接入、验证和版本隔离 |
| 前端/报告 | 用户能理解哪些建议基于部分输入 | 明确显示范围限制、引用来源和未完成状态 |
| 测试/运维 | 无副作用对照、成本、回滚和运行隔离 | 使用只读来源/独立副本，验证无共享库/上传卷写入 |
| 安全/隐私 | 材料、日志和密钥暴露 | 日志不含原文/凭据；盲审材料不纳入 Git |

## 分阶段实施

1. **规格冻结（完成）**：OpenSpec capability 已建立，明确默认关闭、类别覆盖、选择结果、审计和回退要求；用户批准服务端 feature flag 方案。
2. **选择器内核（完成）**：纯函数和合成测试覆盖锚点、类别覆盖、同材料邻接、多主体、多材料、跨页/表格、无词/无命中、OCR 缺页、冲突及异常回退；不调用模型。
3. **辅助路径接入（完成）**：只在 MoMA AI 上下文构造路径集成；固定规则保持完整材料范围；部分范围经现有限制传入提示与引用校验。
4. **审计与快照（完成）**：策略版本及选页指纹进入批次身份和审计事件；策略在 review seed 冻结；旧任务与历史输出不改写。
5. **隔离端到端（技术路径已核验，缩页效果未验收）**：五组普通核查、负面清单、覆盖与报告检查已在隔离副本执行。重建的 SQLite clone 上，当前真实 A1 输入的 36 个合成响应 checkpoint 全部在第二次运行复用；baseline/candidate 的当前模型上下文均为 1,182 页对，输入指纹相同，没有发生缩页。DOCX 通过 Word 三页视觉检查，应用 PDF 四页逐页检查通过。无负面清单建议通过二次证据校验，因此没有可供人工处置的候选。此前已清理 clone 中真实模型 checkpoint 未命中的历史原因无法再现。阶段 5.2 的缩页召回、引用质量和成本收益仍未验收，因为当前没有经审查批准的缩页映射，详见 `2026-11-12-moma-scope-stage5-isolated-verification.md`。
6. **人工验收与发布决策（未完成）**：人工盲审按用户要求暂缓；无人工业务验收不宣称准确性通过。目标环境部署另行授权。

## 验收与回滚

- 选择器开/关时，固定规则结果、材料/规则指纹、人工回执和历史报告保持一致。
- 每个候选页来自当前授权材料；不跨主体/材料借页；无可靠类别覆盖时回退；任何新裁剪均显式标记部分范围。
- 对候选 AI 的每条材料/规则引用继续执行现有逐页原文校验；引用通过不替代事实核验。
- 同一模型、规则、提示和快照下对照输入页、事实类别覆盖、校验通过/拒绝、请求数、token、延迟与失败；仅成本下降不构成上线门槛。
- 默认关闭。服务端只在创建新 review seed 时读取并冻结开关；回滚关闭开关后，新 review generation 恢复基线输入，既有运行按冻结策略继续，历史数据不改写。

实现阶段已获批准，但功能保持默认关闭且当前无获批规则映射，因此现阶段不会缩小任何 finding 的模型输入。下一决策门是补齐可证明的规则映射与未完成的隔离验收；人工盲审仍暂停，目标环境发布另需用户决定。
