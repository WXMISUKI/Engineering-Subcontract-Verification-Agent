## 3 材料一：通用版建设单位审查意见

### 3.1 它负责什么

一份完整的"建设单位对分包合同的审查意见"范文，结构为：

1. **一、审查依据**：5 项（部办法、总承包合同及招标文件、上海细则、监理审查意见、国家禁止转包/欠薪/安全费规定）。
2. **二、总体意见**：原则同意 + 合同须修改后重新备案 + 分包不得减轻承包人责任。
3. **三、具体审查意见**：7 类 22 条——合法性与范围、与总包合同衔接、价款计量支付、质量保修、安全环保人员、工期违约、资料配合。
4. **四、建设单位批复结论**：4 条备案与追责要求。

### 3.2 对报告生成有什么积极作用

| 可用点 | 对应报告区块 | 怎么用 |
| --- | --- | --- |
| "审查依据"分层写法：法律法规 / 项目合同与招标文件 / 监理意见 / 专项规定 | 二、审查依据、附件一依据目录 | 与现有 `_TEMPLATE_BASIS` 合并，形成"法规—项目文件—专项规定"三层，避免依据堆成平铺清单 |
| "总体意见"先定性、再列修改要求 | 五、总体审查意见 | 只借结构：机器只出客观摘要，审批定性仍由人工填写，不能照搬"原则同意" |
| 7 类 22 条**分类维度** | 三、审查情况、四、审查发现问题 | 这 7 类与现有八维度高度可对齐，可作为"问题归类"的二级主题词 |
| "背靠背支付"的正反两种写法 | 四、审查发现问题（合同条款类） | 可作为合同条款类问题的**表述范式**：先写允许写法，再写禁止写法 |
| "计量签认流程：自检→复检→抽检签认" | 四、问题事实、附件二补正要求 | 可作为"程序链条不完整"类问题的描述模板 |
| "资料同步移交、配合审计" | 四、审查发现问题（资料类） | 可作为资料类缺项的事实表述参考 |

### 3.3 不可采纳 / 需废弃的部分

| 内容 | 原因 | 处理 |
| --- | --- | --- |
| 引用"《公路工程施工分包管理办法》（交公路规〔2024〕1号）" | **文号错误**。知识库原始 PDF 与材料三、材料四均为"交公路规〔2024〕**2**号"，已核对原文首页 | 废弃"1号"，统一为 2 号 |
| 安全生产费"不低于 1.5%" | 未在本次知识库法规中找到出处；该数值不能作为判定依据 | 不作为规则；如要写入合同条款提示，须业务方提供现行有效文件依据 |
| 逾期违约金"日万分之×、总额不超 5%" | 属合同合理性建议，非法规强制 | 只能作为"合同条款合理性提示"措辞，不能判"不符合" |
| 缺陷责任期"通常 2 年" | 属合同示范文本口径，上海细则与部办法未作此硬性规定 | 不设为硬规则；以总承包合同约定为准 |
| "91 页 / 34 项 / 具体人名证号 / ××编号 / ×日" | 样例事实，不是当前任务事实 | 全部废弃，一律由当前任务快照动态生成 |
| "原则同意 / 同意按上述范围开展" | 属审批结论 | 不进入机器输出；人工审批意见栏留白 |
| "因承包人原因怠于结算……承包人不得援引背靠背条款抗辩" | 司法口径总结，非上海细则条文 | 可作为合同条款提示语，须标注"非条款依据" |

**净结论**：材料一保留"审查依据三层结构 + 7 类问题分类 + 若干合同条款表述范式"，其余数字、结论、样例事实全部废弃。

## 4 材料二：上海细则 56 条规则清单（DOCX）

### 4.1 它负责什么

把《上海市公路工程施工分包管理实施细则》（沪交行规〔2026〕8 号，2026-08-08 施行，6 章 24 条）拆成 **10 组 56 条**可判定规则，统一编码 `SH-FB-01`～`SH-FB-56`，每条五要素 + 判定处置：

```
规则编号 | 规则名称 | 可判定条件 | 取证字段 | 依据条款 | 判定与处置
```

分组与审查链路：

| 组 | 名称 | 在链路中的作用 | 对报告的落点 |
| --- | --- | --- | --- |
| R1 | 适用范围与定义 | 前置过滤 | 附件一"审查边界" |
| R2 | 分包范围与禁止事项 | 能不能分、分哪些 | 维度1 分包合规性 |
| R3 | 分包人资格条件 | 承接主体准入 | 维度2 资格与信用 |
| R4 | 合同管理与报审流程 | 程序合规 | 维度1 / 维度5 / 附件二 |
| R5 | 转包认定 | 硬性认定 | 维度1，判"不符合" |
| R6 | 违法分包认定 | 禁止行为 | 维度1，判"不符合" |
| R7 | 以劳务合作名义分包 | R6 第（五）项展开 | 维度1，判"不符合" |
| R8 | 视为施工分包违法 | 程序缺陷拟制为违法 | 维度1，易漏判 |
| R9 | 信用、采购、税务、业绩、监管 | 附随义务 | 维度2 / 维度8，多为管理缺陷 |
| R10 | 处罚与施行 | 定性后处置与时效 | 附件一边界说明 |

### 4.2 对报告生成有什么积极作用

这是四份材料里对报告最有用的一份，直接补三个地方：

**（1）八维度的"主要依据"列**

当前维度表"主要依据"是从 finding 的 `source` 反推的，容易空。56 条规则自带"依据条款"，可以按维度预先建立"维度 → 规则 → 条款"映射，让每个维度都有可核对的条款坐标。例如：

| 维度 | 可直接挂接的规则 |
| --- | --- |
| 分包合规性 | SH-FB-04～11、17～23、28～49 |
| 分包人资格与信用 | SH-FB-12～16、50、53 |
| 人员履约能力 | SH-FB-03、13、14、31、48 |
| 设备与资源 | SH-FB-15、30、47 |
| 分包合同条款 | SH-FB-21、22、25、27、40、46、47 |
| 质量安全与进度 | SH-FB-24、26、27、48 |
| 资金与支付风险 | SH-FB-22、32、35 |
| 农民工工资保障 | SH-FB-03、22（仅部分，需另补专户/代发/考勤） |

**（2）附件二五列表的"问题类别 / 补正要求"**

- "判定与处置"列可直接转成**问题类别**：不合规 / 视为违法 / 待核验 / 管理缺陷。
- "取证字段"列可直接转成**补正要求**：缺劳动合同与社保，就要求补劳动合同与社保记录；缺监理书面同意，就要求补审查意见。
- "依据条款"列可直接进入**问题事实**的括注。

**（3）三层判定强度，正好校准报告的三种状态**

材料二自己的"5.1 三层结构"与报告状态可严格对应：

| 规则层 | 材料二定义 | 报告应对应 |
| --- | --- | --- |
| 第一层 硬性禁止（R5/R6/R7 + 负面清单/再分包） | 命中即定性 | **不符合** |
| 第二层 条件核验（R3/R4/R8） | 需比对结构化证据 | **不符合 / 缺项 / —** |
| 第三层 程序管理义务（R9/R10） | 多为管理缺陷 | **不外显为"不符合"**，只作提示或边界说明 |

这一条能直接避免当前报告最常见的错误：把"未建信用台账""未明确采购方式"这类管理义务写成"不符合"。

### 4.3 使用边界与风险

| 事项 | 说明 |
| --- | --- |
| 与向量库的关系 | 上海细则 PDF **已在** `road_shanghai_basis` 集合。56 条是二次加工，**不应作为新法规文本重复入库**，否则同一依据会被召回两次、附件一依据出现重复 |
| 正确入库方式 | 作为**规则条目层**入库，保留 `依据条款` 回指法规原文；法规原文仍是唯一规范依据 |
| 规则可机读性 | 56 条的"可判定条件"是自然语言，不能直接当机器规则执行；需编译成可检索/可判定的条目，否则只能作为提示词上下文 |
| 主体边界 | SH-FB-06、11、50、51、54、55、56 分别指向发包人、主管部门或处置时效，**不是分包合同本身的可判定项**，不能计入"共核查事项" |
| 待业务确认项 | 材料二自己列了 3 项：补批"合理期间"、'有效管理'尺度、大中型工程规模标准映射。这三项未确认前，相关规则只能输出"待核实"，不能判"不符合" |

**净结论**：材料二是本轮最应吸收的资料，但吸收方式是"规则条目 + 维度映射 + 附件字段"，不是"再入一份法规 PDF"。

## 5 材料三：上海专用版审查意见（建设单位 + 监理）

### 5.1 它负责什么

把上海细则与部负面清单**嵌进两份审查意见**：

- **建设单位版 7 条**：分包合法性、现场机构与人员锁定、合同文本与示范文本、劳务合作边界、资金计量审计、信用与业绩、开工前置。
- **监理版 4 条**：前置审核清单、现场管控衔接、违法分包红线（可发暂停令）、资料与备案。
- 另附：**合同"上海专用条款"参考措辞**、**报审材料清单（9 项）**。

### 5.2 对报告生成有什么积极作用

| 可用点 | 对应报告区块 | 怎么用 |
| --- | --- | --- |
| "依据：沪交行规〔2026〕8号 + 交公路规〔2024〕2号 + 负面清单2024版" | 二、审查依据 | 与现有依据模板一致，可作为固定依据三元组的确认 |
| 监理"前置审核清单"要求做"真实性 + 一致性"审查 | 三、审查情况 / 附件一审查方法 | 补强"审查方法"说明：不是只看有没有，而是看证照有效期、人证一致、合同与示范文本对照 |
| "违法分包红线"5 项（无书面同意进场 / 人员无社保挂靠 / 未设现场机构只收管理费 / 劳务队计取主材管资料 / 再分包未报批） | 四、审查发现问题 | 这 5 项可作为**红线类问题**的固定表述，命中即"不符合" |
| 报审材料清单 9 项 | 附件一材料目录、附件二缺项 | 与材料四 10 项、现有 12 类附件期望做**并集**，不要互相替换 |
| 合同"上海专用条款"参考措辞 | 四、问题事实（合同条款类） | 可作为"合同应载明而未载明"的事实描述模板 |
| 建设/监理职责分工 | 附件一边界说明 | 用于说明"本报告不替代监理现场职责"，**不进入责任单位列** |

### 5.3 与当前报告规格的冲突点（必须遵守现有规格）

| 材料三写法 | 当前 V1.3 规格 | 处理 |
| --- | --- | --- |
| 责任单位可为"建设单位 / 监理" | 附件二责任单位**只允许"分包人"或"承包人"** | 保持现状；建设/监理职责写入边界说明，不写入责任单位列 |
| "按上述修改后重新备案，方可实施" | 机器不出审批结论 | 只作为人工审批意见的措辞参考 |
| "三种结论：通过 / 整改后通过 / 不通过" | 机器只有符合/不符合/缺项，且"基本符合"不新建 | 不引入第四种状态；该三态只用于材料四的人工勾选 |
| 安全生产费、缺陷责任期等具体数值 | 与材料一同问题，无本次可核依据 | 同材料一处理：不作硬规则 |

**净结论**：材料三采纳"前置审核清单 + 5 条红线 + 报审材料清单 + 专用条款措辞"，不采纳其审批结论口径和责任单位扩展。

## 6 材料四：上海公路分包合同合规审查表（XLSX）

### 6.1 它负责什么

8 个工作表的勾选式审查表：

### 6.2 对报告生成有什么积极作用

**（1）补齐现有八维度里"未覆盖"的三个维度**

当前"设备与资源""资金与支付风险""农民工工资保障"没有独立核查能力，只能写"本版本未覆盖"。材料四给出了这三块**检查项级的骨架**：

| 维度 | 材料四可提供的检查项 |
| --- | --- |
| 设备与资源 | 设备清单、权属/租赁证明、检定证书（sheet 7 第 5 项） |
| 资金与支付风险 | 计价口径、背靠背、计量流程、审计结算、资金专户/财务监理（sheet 3） |
| 农民工工资保障 | 实名制、专用账户、总包代发、工资代付、信用档案（sheet 6） |

注意：有检查项 ≠ 有自动核查能力。这些只能作为**"应查要点"和"缺项判断"**，不能直接生成"符合"。

**（2）报审材料清单可直接映射附件一和附件二**

材料四 10 项与现有 12 类附件期望做并集，增量清楚：

| 材料四新增/更具体 | 现有附件期望缺失或较粗 |
| --- | --- |
| 分包合同正本（含修改对照稿） | 现有只有"合同全文及工程量清单" |
| 安全生产费使用计划 | 现有只归入 payment 大类 |
| 农民工工资专用账户及代发协议 | 现有只归入 payment 大类 |
| 《负面清单》对照说明 | 现有无 |
| 分包管理台账（承包人建） | 现有无 |
| 主要人员"工资流水" | 现有只有劳动合同、社保 |

反向，现有比材料四多出的：银行开户证明/法定代表人身份证明/授权委托书、类似业绩与信用查询、劳务人员花名册与培训、施工方案与应急预案。**结论：两者互补，应取并集，不能拿材料四替换现有目录。**

**（3）封面信息可作为报告基本情况的字段校验清单**

项目名称、合同编号、发包人、承包人、拟分包人、分包内容、合同金额、拟开工/完工、报审编号、审查日期——正好覆盖报告"一、报审基本情况"和附件一"审查概况"的字段。可用于检查报告漏填，不可直接当事实来源（表内为空）。

**（4）三方签署栏 → 报告落款与人工审批**

承包人自查、监理审查、建设单位结论三段签署，正好对应报告"审查人/复核人/签发人"与"人工审批意见"，**只能作为留白结构参考，不能生成签署事实**。

### 6.3 不可采纳的部分

| 内容 | 原因 | 处理 |
| --- | --- | --- |
| 表内预填的"符合" | 是表单默认值/示例，不是本任务结论 | 废弃，严禁作为判定输入 |
| "1.5% 安全生产费""缺陷责任期 2 年""违约金不超 5%" | 同材料一，无本次可核依据 | 只作合同条款提示，不判"不符合" |
| "通过/修改后通过/不通过" | 与机器三态不同 | 仅用于人工审批栏表述 |
| 表内空白或"是"的默认勾选 | 非真实数据 | 废弃 |

**净结论**：材料四是"检查项与材料清单"的最佳来源，采纳其**覆盖面**，拒绝其**预填结论**。

## 12 一句话总结

这四份资料对本项目的价值不是"又多了一批法规"，而是：**材料二提供了规则骨架，材料四提供了检查项与材料清单，材料三提供了上海专用的红线与措辞，材料一提供了审查意见的文体。** 报告格式不用大改，真正要补的是"八维度—规则—依据"的映射关系和附件材料目录的并集；凡是带具体数值、样例结论、审批口径、错误文号的内容，一律废弃，不进入报告。
