# V1.4 vs V1.3：版式、表格与内容问题分析

日期：2026-11-17。来源：V1.4 真实导出 DOCX、V1.3 真实导出 DOCX、两份文档的段落/表格样式解析。

结论：V1.4 现在“不如 V1.3 清楚”，有三个独立原因，必须分开修：

1. **版式不一致**：V1.4 用了 Letter 纸张、2.2cm 边距、10.5pt、9pt 表格；V1.3 是 A4、3.2cm 边距、11pt、轻表格线。观感差异主要来自这里。
2. **内容没有摘要**：V1.4 把每个缺项单独列一条，重复“报审资料缺 XX”；V1.3 按“企业资格与业绩资料 / 人员及履约资料”分组，一段说清。
3. **内部术语和截断**：V1.4 正文出现“R10 未形成机器结论”“R4 能力未覆盖”“请一并提供以核对各自…”，用户看不懂。

---

## 1 版式差异（硬指标）

| 项 | V1.4 实际 | V1.3 实际 | 判断 |
| --- | --- | --- | --- |
| 纸张 | 21.6 × 27.9 cm（Letter） | 21.0 × 29.7 cm（A4） | **V1.4 错，应改 A4** |
| 页边距 | 左右 2.2，上下 2.0 | 左右 3.2，上下 2.5 | V1.3 更适合公文 |
| 正文 | 宋体 10.5pt | 宋体 11pt | V1.3 更舒展 |
| 一级标题 | 12pt 加粗 | 模板样式（约 12pt） | 接近，但 V1.4 缺段前距 |
| 行距 | 未显式设置 | 模板样式（更松） | V1.4 偏挤 |
| 缩进 | 项目符号左缩进 0.8cm | List Paragraph 左缩进 0.79cm | 接近 |
| 表格 | 7 张，`Table Grid`，9pt | 2 张，`Normal Table`，11pt | **V1.4 表格太密、太重** |

**这是“观感差”的第一原因**：Letter 比 A4 短，页面更矮；边距更小、字号更小、表格 9pt，整页会更挤。

### 建议

- 纸张改 A4（21.0 × 29.7）；
- 页边距左右 3.2cm、上下 2.5cm；
- 正文宋体 11pt，行距 1.5；
- 一级标题 12pt 加粗，段前 6pt、段后 6pt；
- 表格 10.5pt，使用 V1.3 的轻表格线，不用 `Table Grid` 的粗网格；
- 项目符号左缩进 0.8cm，段后 3pt。

---

## 2 表格差异

| 项 | V1.4 | V1.3 |
| --- | --- | --- |
| 数量 | 7 张（8 表附件） | 2 张（维度表 + 问题清单） |
| 样式 | `Table Grid`，9pt | `Normal Table`，11pt |
| 列 | 审查项 / 结论 / 判定理由 / 补正要求 | 序号 / 审查维度 / 主要依据 / 初审意见；序号 / 问题类别 / 问题事实 / 补正要求 / 责任单位 |
| 单元格内容 | 长句 + “审查要点” + 规则编号 | 短句、分组、可读 |
| R4 重复 | 表 3–5 大量“R4 能力未覆盖” | 无 |

**问题**：V1.4 表格不是“更好看”，而是“信息密度过高”。9pt 长句 + 粗网格，视觉疲劳。

### 建议

- 表格改用 V1.3 的轻线样式（`Normal Table` 或自定义细边框）；
- 字号 10.5pt，行高一致，表头浅灰；
- 正文只保留一张“审查维度状态”表（V1.3 四列样式）；
- 8 表附件放最后，每张表只保留“审查项 / 结论 / 审查说明 / 补正要求”，不再重复“审查要点”；
- R4 未覆盖项不逐行重复，表头下加一句“本表未覆盖事项：质量目标、缺陷责任期……”，表内统一写“—”。

## 3 内容问题（逐条对应你看到的）

### 3.1 “R10 未形成机器结论”

**出现位置**：V1.4 第 2、3、5 章结论，共 3 次。

**问题**：内部状态码，用户无法理解。

**修复**：

- 正文不出现 R10/R4；
- 改为“本次未取得可核对材料，暂无法形成结论”；
- 内部状态码只保留在系统页面/审计记录。

### 3.2 每个缺项单独一条，重复“报审资料缺 XX”

**V1.4 现状**：第 6 章列出 8 条：

```
· 注意：报审资料缺「分包工程清单（项目部红章）」（报审包内未见名称或文本依据）
· 注意：报审资料缺「营业执照」（报审包内未见名称或文本依据）
· 注意：报审资料缺「资质证书」（报审包内未见名称或文本依据）
...
```

**V1.3 写法**：

```
企业资格与业绩资料。当前核查记录列示资料缺项：营业执照、资质证书、
安全生产许可证、诚信手册（沪）、本地类似业绩清单（近 3-5 年）。
```

**修复**：按类别归并，一条说清：

```
· 注意：企业资格与业绩资料缺项：营业执照、资质证书、安全生产许可证、
  诚信手册（沪）、本地类似业绩清单（近 3-5 年）。
· 注意：人员及履约资料缺项：身份证、交安A证、主要管理人员名单、
  学历证、职称证、交安C证、社保证明。
```

“报审包内未见名称或文本依据”只写一次或不写。

### 3.3 “请一并提供以核对各自…”

**出现位置**：第 4 章“全部工程肢解后分别发包”一条，末尾被截断。

**原因**：实现里对超过 140 字的“需核实”做了 `text[:140] + "…"`，截在句子中间。

**修复**：

- 不再按字符截断；
- 先按句号/分号切句，取第一句；
- 第一句仍过长时，改写成摘要：“需核实：是否将全部工程肢解后分别发包；现有材料缺总包范围和其他分包合同。”
- 完整原文放附件/系统明细，不放正文。

### 3.4 “已核查通过”误用长条款

**V1.4 现状**：第 4 章出现：

```
· 已核查通过：三、涉及大型滑坡、泥石流、冻土等不良地质和特殊性岩土处治工程，
  大型支挡防护工程，特殊高填深挖路基，有特殊技术要求的路面工程，桥面（隧道）
  铺装工程等，是否增补纳入负面清单，由省级交通运输主管部门……自行确定。。
```

**问题**：这是负面清单的授权条款，不是“已核查通过”的事实；末尾还有两个句号。

**修复**：

- “已核查通过”只收真正的检查项，不收长法律条款/开放条款；
- 过滤 `len(label) > 40` 或 `open_term` 的项；
- 负面清单授权条款归入“审查边界”，不写成通过。

### 3.5 “劳务内容”用了桩号

**V1.4 现状**：

```
劳务内容：K1287+958.203~K1289+454.891、K1289+939.227~K1293+094
```

**问题**：这是范围/桩号，不是劳务内容。领导样例写的是“预制构件吊装劳务”。

**修复**：

- 优先取“分包事项/分包内容”短名；
- 桩号范围放括号里或下一行“范围”；
- 没有短名时写“劳务内容：详见报审范围（桩号……）”，不要把桩号当内容。

### 3.6 结论条件还是通用句

**V1.4 现状**：

```
1. 请结合问题描述核对合同及相关资料，完成整改后重新核查。
```

**问题**：不是可执行条件，和领导样例的 5 条条件差距大。

**修复**：

- 从问题类型生成具体条件：补安许、补合同、补社保、补人员证书、明确关键工序；
- 同类条件合并，最多 5 条；
- 没有具体条件时，不硬写通用句，留“要求：按报审材料实施”。

### 3.7 “无法判断/需核实”重复且没有具体缺什么

**V1.4 现状**：11 次“需核实”，多条以“无法判断”结尾，缺什么写在括号里但很长。

**修复**：

- 每条“需核实”只保留三要素：核实什么、缺什么、找谁补；
- 同类合并；
- 不写“无法判断”作为结论，写“需核实”。

### 3.8 数据误判仍在

**V1.4 现状**：第 6 章仍把营业执照、资质证书、安全生产许可证列为缺项；第 3 章社保仍判未识别。

**原因**：证照/社保匹配逻辑问题，不是版式。

**修复**：

- 证照：文件名 + 内容双匹配，合同附件中的证照要能被识别；
- 社保：解析“参保人员城镇职工基本养老保险参保情况”表；
- 劳务资质：施工劳务不分等级，证书载明即满足；
- 先修数据，再谈文案。

## 4 应该向 V1.3 学什么

| V1.3 做法 | 是否借鉴 | 说明 |
| --- | --- | --- |
| A4、3.2/2.5 边距、11pt | **直接借鉴** | 公文观感 |
| 轻表格线、11pt 表格 | **直接借鉴** | 8 表附件也用 |
| 缺项按类别归并 | **直接借鉴** | 一段说清一类缺项 |
| 八维度状态表 | **借鉴但精简** | 正文只放一张“审查维度状态”表 |
| 五列问题清单 | **借鉴到附录** | 正文不放大表 |
| 维度状态汇总（符合/待核实/不符合/缺项） | **借鉴** | 比“R10 未形成结论”清楚 |
| “报审包内未见名称或文本依据” | **不借鉴** | 内部术语，重复 |
| “待核实项：8 个维度名” | **不照搬** | 太笼统，要写具体缺什么 |

## 5 建议的修复顺序

### P0 版式与文本（先让报告能读）

1. A4 + 3.2/2.5 边距 + 11pt + 1.5 行距；
2. 表格改轻线、10.5pt；
3. 正文删除 R10/R4；
4. 缺项按类别归并；
5. 去掉字符截断，改句子摘要；
6. “已核查通过”过滤长条款；
7. “劳务内容”用事项短名，桩号放范围。

### P1 数据与结论

1. 证照缺失误判；
2. 社保匹配；
3. 劳务资质不分等级；
4. 结论条件按问题类型生成；
5. R4 行合并。

### P2 结构与表格

1. 正文加一张 V1.3 风格的“审查维度状态”表；
2. 8 表附件按 V1.3 轻线样式重排；
3. 附录问题清单用 V1.3 五列格式。
