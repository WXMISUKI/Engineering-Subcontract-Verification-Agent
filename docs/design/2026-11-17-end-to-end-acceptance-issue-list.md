## 0 总体结论

全链路已经能跑通：材料解析 → 五步核查 → AI 辅助 → 人工复核 → V1.4 正式意见 → Word/PDF → 8 表工作底稿导出。报告层的主要问题已处理，结论规则、证照事实、安许续期、8 表导航和人工回执沿用标识均已落地。

剩余问题不在“页面排版”，主要集中在三类：

1. **证据抽取仍有漏匹配**：社保记录明明存在，A2-01 仍判“未识别到社保缴费记录”；人员证书与岗位对应仍未闭环。
2. **规则覆盖不足被写成了“已核对”**：负面清单只覆盖 1/21，报告却写“已对负面清单关键性工作进行核对”；合同第 46–62 页已在册，第 5 章仍写“本次未涉及”。
3. **报告口径仍有内部术语和数字不一致**：正文仍保留“本次共核查 50 项”，与数据库 88 条记录不一致；出现“法定签字链”等内部叫法。
