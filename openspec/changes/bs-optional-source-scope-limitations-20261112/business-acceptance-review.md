# 阶段 7.1 业务验收材料

状态：A（UI 文案）、B（报告边界）和 C（来源状态处理）均已获用户确认。本文不代表 rollout flag 启用、盲审或部署批准。

## 本次验收范围

阶段 0 已确认的产品原则不重新提请审批：专业或劳务分包合同是核查基础，总包合同是可选上下文；缺少总包只影响规则来源矩阵中确实依赖总包的规则；范围限制不生成 finding、不算符合、不单独阻断正式分包报告；真实 `undecidable`、必需执行失败和运行中状态仍按既有门禁处理。

当前矩阵将总包来源依赖限定在 T15-01、T15-02、T15-03、T15-05、W16-03、V16-02。其他规则不因缺少总包而跳过。金额比例规则仍默认关闭，不属于本次启用范围。只有多份相互独立且关系未明确的总包才构成材料准入/归属错误；同一总包的分册、附件或补充协议可由用户明确关联为一个来源集后继续核查，不自动择一。

## 当前实现与待确认文案

待处理工作区单独展示“范围限制”，不进入问题待处理清单，也没有采纳/忽略操作。用户已接受将 UI 文案改为：

> 以下规则本轮未覆盖，未形成符合或不符合结论，也不会进入问题待处理清单。

正式报告的范围段落当前说明：

> 本轮存在以下规则范围限制；相关规则未形成符合或不符合结论，也不计入通过。

并逐条列出规则及来源状态。受限业务文档的结论当前为：

> 在本次已覆盖核查范围内，未发现需要处理的问题；部分规则本轮未覆盖，相关规则未形成符合或不符合结论，不能解释为完整通过。具体规则见范围限制。

意见书摘要也使用“本次仅能就已覆盖范围形成意见；仍有规则未覆盖，不能解释为完整通过”的边界。

## 来源状态与闭环

- **总包未提供**：用户只上传了分包合同。矩阵中需要总包对照的规则本轮未覆盖；不产生 finding，也不影响其他分包规则继续执行。
- **总包仍在解析**：用户刚上传了总包，文件尚未读取完成。此时不能判断它可读或不可读，也不能当作“未提供”；覆盖状态保持处理中/未完成，报告就绪门禁阻止提前正式出具。解析结束后再根据读取和归属结果继续。
- **单份总包终态不可用**：解析已经结束，但文件没有可用文字、规则需要的页面无法读取，或无法确认材料属于当前任务/主体，或来源信息互相冲突。系统不把它当作可靠证据；只限制实际依赖该总包的规则，披露具体原因，其他规则继续。范围限制不算 finding 或符合。
- **多份总包**：若材料识别为多份相互独立的总包，且用户尚未说明它们与当前任务的关系，属于材料归属/准入歧义，需先由用户选择或说明关系；不能把它弱化成普通范围提示，也不能由系统自动选择最新或第一份。若多份文件是同一总包的分册、附件或补充协议，用户可将其明确关联为一个来源集，系统再按该来源集处理。
- 补件上传本身不清除限制；解析、归属确认和新核查代中受影响规则执行完成后，当前代提示才可解除；历史版本仍保留当时快照。
- 仅有范围限制且其他报告门槛均满足时可正式输出受限报告；真实 `undecidable`、必要核查未完成/失败仍按原门禁处理。

## 已确认的业务口径

1. UI 使用“以下规则本轮未覆盖，未形成符合或不符合结论，也不会进入问题待处理清单。”
2. 报告/意见书在存在范围限制时仅对已覆盖范围形成意见，不得解释为完整通过，并逐条列出未覆盖规则及原因。
3. 总包仍在解析时沿用现有报告就绪门禁；单份总包终态不可用、未关联或来源冲突时，只限制依赖该来源的规则并披露原因；多份独立总包且关系不明时阻断，确认属于同一总包的分册、附件或补充协议后，可关联为一个来源集继续处理。
4. 2026-11-12，用户选择“显式关联并保留各原件”：用户在 setup 阶段明确选择同一总包的多份材料建立来源集；系统不按文件名或时间自动合并，各上传原件继续独立保留。完整来源集在启动准入中按一份总包来源计数，拆分或失效关联后按独立来源重新检查；关联、扩组、合并和解除均写入操作者审计事件，当前关系版本进入核查代快照；改类、删除会解除关系，替换材料后需重新确认。该选型只确认实现方式，不代表开启业务 flag、候选 rollout 或部署。

## 验收边界

本次业务验收不校核法规原文或逐规则法律解释；规则矩阵记录法规资料仍待规则/合规负责人校核。MoMA AI 选页真实缩页效果属于独立验收项，当前无已批准缩页映射，仍需合法可用的同一主线总包与分包样本；这不构成总包必传要求，也不改变本变更的分包核查语义。

通过本阶段验收不启用 `BS_OPTIONAL_SOURCE_SCOPE_LIMITATIONS_ENABLED`，不改变 `BS_MOMA_SCOPE_SELECTOR_ENABLED`，不恢复盲审，也不授权候选环境启用或部署。rollout 与部署分别属于阶段 7.2、7.3，需另行决策。
