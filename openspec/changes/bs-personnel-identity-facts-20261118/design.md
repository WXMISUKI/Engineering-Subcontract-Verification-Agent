# 设计

1. 身份号只作明示字段候选：NFKC、去首尾空白、x转X，不补掩码或纠OCR，不声称公安验真。沿用既有18位候选口径。表格仅取身份证对应列；显式证明只取同一人员段，缺失和多候选原样保留。
2. 名单保持已有电话/同行列/布局防误取约束，附加岗位、身份证、职称等可定位字段。社保拆行记录的原始姓名行、号码行及期间续行合并保留引文，不借下一人字段。
3. 材料事实每页新增一条`personnel.records` JSON数组；每项保留姓名、岗位、证件候选、单位/期间、证据类型及引文。绕开同页同field唯一键覆盖多人问题，沿用批次幂等和历史保留。提取器版本递增，既有单值路径保持兼容。
4. A2-01在当前主体内优先按明示身份证候选配对；同名异号不合并，不借另一人的合同/社保判通过或不符合。缺号按姓名+单位作候选兜底，说明身份仍需核对；多号/姓名冲突进入待核实。证书关系的既有person_key和人工复核契约不在本切片改写。
5. 社保离散缴费月份不能用最早/最晚月份补成连续区间。只承认明确区间及实际列举月份；期间不明保持待核实。

本地合成用例验证同页同名异号、拆行、掩码、主体隔离、append-only和离散月份。真实材料覆盖仍在第五阶段验收。
