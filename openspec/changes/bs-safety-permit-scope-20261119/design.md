# 设计

- service.run_cert_validity的逐主体路径追加A2-09，沿用cert_validity，纳入重跑目录和报告安许分节，不修改旧报告快照。
- a2_check复用_certificate_text及extract_certificate_facts，每次仅送入同一材料同一页；不跨页拼接证号/单位/许可范围，不从营业执照经营范围借字段。模板、提交义务和清单不作为实证。
- 缺安许或范围字段且相关材料完整可读=缺项；未读/主体不明/名称冲突/范围映射未验证=待核实。安许期限沿用A2-02，不把范围核查再次升级为期限违规。没有已验证范围规则时不产生hit或miss。
- 名称一致仅作归属候选，不鉴定证照真伪；必须保留企业名称、证号、范围、材料、物理页和原文证据。出现不同单位/范围的证照候选不择“最完整”自动通过。
- V14安许分节有结构化范围结果时必须使用finding结论，不能被旧证照摘要“有效期覆盖”盖掉范围待核实或缺项。新增报告白名单/标签及影响/建议文案。
