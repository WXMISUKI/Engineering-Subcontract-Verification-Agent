# 任务执行诊断与日志关联

长时间核查只显示通用处理中状态，运维又无法从任务事件快速关联后台执行日志，导致页面不能判断停滞阶段、后台日志也缺少定位同一任务运行的信息。本变更补齐任务运行状态、事件回执与结构化后端日志之间的关联，并在核查页展示诊断信息。

## 范围

- 后台 AI job 状态返回最近进度时间、分组、批次、请求关联标识及停滞候选状态。
- 任务事件安全投影暴露诊断所需的阶段、关联标识、批次和受控失败类别。
- 后台 AI 异常日志以任务、运行代、job、分组和请求关联字段记录；异常文本不得包含密钥、提示词或材料正文。
- 核查页展示当前阶段、最后回执时间、关联 ID、失败类别，以及状态无法核实时的明确提示。

## 非目标

- 不接入新的外部日志平台或告警渠道。
- 不读取、重试、重放或修改线上任务；本地代码实现不代表已经部署。
- 不新增任务事件的业务结论，不改变报告、人工复核或恢复门禁。
