# 人员工程规模原件纠正及参数链路

## Why

DG/TJ附录A第28物理页视觉复核发现旧评审表格跨行错位：一级公路使用了二级及以下阈值，二级及以下误设固定小型。当前入口只传合同额，且不呈现初判不完整性，可能低估岗位配置及后续职称所需规模。

## What Changes

- 归档原PDF/选页文本/表格图像与哈希，区分原文核对和现行效力。
- 用户选择按原件纠正后再更新当前规则，不回写旧快照；如选择业务自定义分档，另记为业务规则，禁止冒称原文。
- 补齐同一分包合同范围的规模参数、来源及冲突保留；已确认最高档可判，缺参数的较低档只作初判并待核。
- 将规模及其来源/缺口进入既有A2-07工作台和报告；岗位专业/职称仍待此基础完成后另切片验收。

## Impact

现有人员配置数据、内核及A2入口和正式回归。无新数据库或付费执行，不改既有任务/历史报告/线上知识库或部署。具体原文及待确认项见docs/design/2026-11-19-dgtj-scale-original-alignment-review.md。
