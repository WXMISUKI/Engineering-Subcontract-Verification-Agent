# 当前源码的隔离文本集成验收

## Why
各事实切片已分别验证，仍需检查同一真实材料已有文本进入五组规则和报告后的集成行为；单项候选回放不证明全流程一致。

## What Changes
- 使用现有 task12 私有文本快照，在内存 SQLite 重建复制任务、主体和材料，不连接业务数据库。
- 使用临时合成依据映射且不配置任何知识 Provider，阻断全部网络连接；五组规则按依赖顺序执行，报告继续使用原门禁。
- 只保存不含业务原文、姓名、文件名和身份证号的计数与校验结果，保留失败，不放宽产品门禁。
- 原PDF只读视觉核对若证实主体角色录入冲突，允许另建仅内存主体修正对照；不得把对照当作源任务更正或用户确认。
- 区分已有文本回放、合成 HTTP 与真实浏览器/Provider/业务/部署验收，更新下一批入口。

## Impact
仅新增验收记录与任务收口说明。源 task12、历史报告、原快照和部署不变；缺失的项目元数据和图像信号不补造。本次不能关闭主9.x真实业务验收。
