## ADDED Requirements

### Requirement: 隔离确定性文本验收不得改变业务事实
系统验收 MUST 在独立数据库使用复制的已解析文本，保持源快照、源任务和历史报告不变，不触发新OCR、在线模型或知识检索。

#### Scenario: 五组规则及报告集成回放
- **WHEN** 使用当前源码对既有私有文本快照执行隔离验收
- **THEN** 五组规则按依赖顺序运行，报告仍通过原有一致性与话术门禁，失败必须保留
- **AND** 统计产物不包含业务原文或个人身份值
- **AND** 结果仅证明已有文本范围内的集成行为，不证明真实Provider、图像识别、真实履约或部署通过
