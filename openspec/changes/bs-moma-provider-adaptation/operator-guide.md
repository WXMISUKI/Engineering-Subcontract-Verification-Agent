# MoMA 适配配置与验收说明

状态：仅本地模拟验证；具体模型、端点及目标环境安全条件未经验证，不能据此宣称已跑通生产服务。

## 数据流和责任

分包材料原件保存在应用受控存储中，电子文档文字和扫描页识别结果可能作为业务模型输入。扫描页渲染为 PNG 后以 Base64 放入请求，发送给配置的 MoMA 图片理解服务；该编码不是加密，也不代表文件未出云。传输要求 HTTPS、证书验证、访问控制及出站白名单。部署方必须审查代理、网关、APM 和日志的请求体采集配置，禁止记录材料内容、图片或密钥；本次改动不能证明所有基础设施日志均已脱敏。

当前适配依据 [MoMA Qwen 图片理解接口](https://ecloud.10086.cn/op-help-center/doc/article/93315) 和 [模型对话接口示例](https://ecloud.10086.cn/op-help-center/doc/article/94470)。具体模型卡可能存在参数、最大输出、并发、计费、输入大小和响应差异；特别是图片接口文档中 HTTPS 与 HTTP 示例不一致，须由移动云确认可用的 HTTPS 或私网 TLS 地址，不能使用 HTTP 发送材料及凭据。不得推断平台文件默认私有、自动删除或不用于训练。

## 配置

在部署主机通过受控密钥注入机制配置以下变量，值由业主及移动云提供；不要把真实密钥写入代码、镜像、交付包或聊天。地址示例仅表示形态，不是可用地址或模型推荐。

```dotenv
LLM_PROVIDER=moma
LLM_MODEL=<业主批准的文本模型标识>
LLM_API_BASE=https://<已核验文本节点>/v1
LLM_API_KEY=<由受控环境注入>
OCR_CLOUD_PROVIDER=moma
OCR_CLOUD_MODEL=<业主批准的图片理解模型标识>
OCR_CLOUD_ENDPOINT=https://<已核验图片节点>/v1/chat/completions
OCR_CLOUD_API_KEY=<由受控环境注入>
```

文本地址是 OpenAI SDK 的 base URL，OCR 地址是完整的 Chat Completions URL。文本和 OCR 可以分别配置为 `legacy` 或 `moma`；缺省 `legacy` 保持既有行为，切换前必须确认该链路所指实际服务商已经获批。MoMA 参数不发送 `enable_thinking` 和 `prompt_cache_key`，需要模型支持普通非流式消息与业务 JSON 输出。端点必须 HTTPS 且不含 URL 用户名、密码、查询字符串和片段；不会跟随重定向。未知 provider 不发送请求。

业务任务所绑定或计费默认的模型编码必须与 `LLM_MODEL` 一致；部署人员应核对模型登记、调用权限与价格配置，否则模型客户端会拒绝该任务。不要在未验证价格和结算口径前启用实际扣费。

该实现按上述特定图片文档的限制，要求编码后的图片小于 4,000,000 字节；超限不压缩、不静默识别，进入未读/人工核实。模型只返回页文本，不提供词框：不能承诺坐标级定位或批注，需在业务验收中核实影响。截断、空响应和失败均不能判为读完。独立版业务 OCR 保持线上模式，不使用本地 OCR、旧缓存或另一供应商兜底。模型文本也可能识别或推理错误，须保留原件对照与人工复核。

业务文本模型沿用已有 usage 回调；OCR 适配器能向直接调用者提供服务返回的 usage，但当前分包解析路径尚未传入该回调，任务页账务不能据此视为完整的 OCR 用量或费用。应以 MoMA 平台账单核对，费用归集闭环另行完善。没有返回 usage 不得当作零成本。知识库 Embedding、知识视觉模型和 WeKnora 配置不由此自动切换。

## 部署前确认与验收

1. 由业主及移动云确认具体模型、实际数据处理方及地域、网络与证书、模型许可、材料保留与删除、训练使用、分包方和审计条款；确认文字与页图许可覆盖证件、签章等实际材料类型。
2. 在隔离环境配置获批端点、最小权限密钥、出站白名单和预算；检查基础设施日志和代理不保留敏感请求。先用合成文字与扫描页检查模型 JSON、表格/证件识别、图像大小、页号、无坐标行为、非直链、错误/超时/截断、用量和无跨供应商回退。
3. 经业主授权后用真实样本核对识别准确性、人工复核、报告与费用；记录具体版本、服务节点、结论及责任人。模拟响应、健康检查和通用官方示例均不能替代真实模型联通或安全验收。
4. 评估切换对既有任务及 AI 检查点复用的影响；不能假定新旧模型结果等价。若需回滚，按获批版本和配置执行，先确认回滚的服务商也获准处理数据。
