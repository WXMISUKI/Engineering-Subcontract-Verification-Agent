# MoMA 适配交接说明

日期：2026-11-10。状态：代码候选、合成数据和模拟接口验证通过；真实 MoMA 联通、安全审查与业务验收尚未完成。

## 交付位置与基线

- 独立仓库 `Engineering-Subcontract-Verification-Agent`：交接分支 `codex/moma-adaptation-20261110`，从 `origin/main` 的 `17893ba08f26dad28dee34dd3c08913f191840bc` 建立，仅包含本次 MoMA 相关代码、配置、测试及文档。
- 原独立项目本地 `main` 当时比 `origin/main` 领先两个既有提交，同时有大量其他未提交业务改动；MoMA 代码也保留在该原工作区。交接分支没有包含这些改动，不能把分支测试结果当作原工作区全部内容的验收。对原工作区合并、拣选时必须先核对这些未提交改动，避免覆盖或重复应用。
- 智能体广场与独立版不是同一份代码。本分支没有改造广场版，也不证明广场版支持 MoMA。若广场版要直接对接 MoMA，应另立规格，评估平台模型路由、OCR、计费及权限后实施。

## 已完成内容

业务文本通过 `LLM_PROVIDER=moma` 选择普通 Chat Completions 协议；扫描页通过 `OCR_CLOUD_PROVIDER=moma` 选择图片理解转写。默认 `legacy` 维持各链路原配置。两者都要求显式配置模型、地址与凭据；MoMA 端点要求 HTTPS，不跟随重定向；未经配置或出现异常不会自动切换到其他供应商。独立业务 OCR 原有失败进入未读或人工核实的语义保留。

扫描页以 PNG 的 Base64 data URL 作为请求内容，不建立公网文件直链；页面图像和文字仍会发送到配置的服务。截断、空响应、超限均失败，现有适配不提供词级坐标。MoMA 与 legacy 的 AI 批次检查点指纹隔离，避免仅切换协议时误用旧结果。详细配置、安全责任和模型接口限制见 [配置与验收说明](operator-guide.md)。

1. 阅读本文件、[设计](design.md)、[任务清单](tasks.md)、[配置与验收说明](operator-guide.md)，核对当前独立仓库分支、远端及工作区。先确认相关未提交工作归属，禁止 `reset`、`clean` 或整体覆盖。

3. 向业主和移动云核对文本与图片模型、完整 HTTPS/私网 TLS 地址、模型输入/响应协议、输出限制、实际处理方、地域、留存、训练、分包、安全审计、出站域名、测试额度和证书。凭据由业主通过密钥管理服务或受控环境注入，不提交或放进聊天。
4. 先使用合成数据验证真实模型调用及 JSON 输出、扫描页准确率与物理页码、超限/截断/失败处理、无词框的界面和报告行为、用量和费用、日志脱敏以及出站目的地。不得将成功的单次请求视为性能或安全结论。
5. 经业主授权后开展真实材料及业务专家验收，记录版本、模型、数据边界、费用、失败和回滚。将 OCR 用量归集作为独立待办处理，在此之前以平台账单核对；各项目标环境、数据和安全门槛单独签认。
