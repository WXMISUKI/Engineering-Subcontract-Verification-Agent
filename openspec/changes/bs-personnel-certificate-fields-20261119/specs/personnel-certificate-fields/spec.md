## ADDED Requirements

### Requirement: 名单声明与证书来源分别保存
系统 MUST 保留同一名单行明示的职称、证书类别/编号/期间，同时单独保存实际证照段候选，不将名单声明当作证书已提交。

#### Scenario: 同页两人及两份证书
- **WHEN** 同一材料页载有多条人员或证照
- **THEN** 每条记录保留本人的字段、材料、页和原文，不跨行或证照段补值

### Requirement: 身份关联保持证据边界
系统 MUST 只在同主体、姓名与唯一完整身份证候选一致时标注身份字段对应，无号或冲突仅形成待核实候选。

#### Scenario: 同名异号或跨主体
- **WHEN** 证书姓名相同但号码不同，或属于另一主体
- **THEN** 不借用证书字段证明本人员持证，保留待核实原因

#### Scenario: 字段齐备
- **WHEN** 所附证照与名单身份字段对应且证书字段齐备
- **THEN** A2-10仍为待核实，不据此宣称原件真实、岗位资格合格或有效期已通过

### Requirement: 事实与报告可追溯
系统 MUST 将新人员记录以新抽取批次追加落库，A2执行及报告使用同源字段，不改写历史批次或历史报告。

#### Scenario: 重复解析与重核
- **WHEN** 相同批次重复解析或A2重复执行
- **THEN** 事实不重复插入，A2-10按既有替换规则幂等，旧批次内容保持原样
