# 实施设计

- 沿用personnel_evidence名单列与material_facts的personnel.records数组；新增证书抽取器只消费已落库文本，不调用OCR或Provider。证书记录保留字段候选数组及原文，不从文件名、身份证有效期或相邻证照补值。
- 独立证照标题限定注册建造师/安全考核/特种作业/特种设备作业/职称等已有业务范围；不将合同义务、目录、模板、名单行当实际证件。每页按独立文档标题切段，同页多人多证单列；缺号/日期仍保留候选，不生成虚构字段。
- A2-10复用a2_check._person_relation_pool及_person_key，只允许同主体、姓名和唯一完整身份证候选形成身份对应。无号仅候选；同名多人或字段冲突不合并。记录字段对应不等于身份证真伪/证书真实性已核验。
- A2-10挂既有cert_validity分组、逐主体服务、重跑目录、报告白名单。只输出undecidable，缺抽取字段不直接判法定缺证或不符合，不修改A2-01劳动社保结论或A2-05既有项目经理B证关系。
- 报告区分字段/归属与A2-02有效期，候选完整仍人工核对岗位适用性和原件。更新规则指纹与V14映射，不重写历史结果。
