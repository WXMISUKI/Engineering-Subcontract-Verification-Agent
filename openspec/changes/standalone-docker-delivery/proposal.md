## Why

工程分包审查当前依附智能体广场及外部知识服务，无法作为可控的独立 Docker 离线交付物交给业主。

## What Changes

- 建立独立代码仓库和工作台入口，保留五步审查、材料解析、人工复核、补件及报告等已确认业务流程。
- 提供不开放注册的登录及任务持久化；不设单位，账号只能查看和操作自己的任务及材料。
- 以一个 Compose 入口编排应用、数据库和随包交付的 WeKnora 必需服务；提供版本锁定的离线镜像、配置模板和校验清单。
- 支持部署方分别配置模型、OCR、Embedding、Rerank 和知识服务；不携带现有环境密钥或真实业务数据。
- 将现有分包智能体实际使用的知识资料复制到离线交付包并重新建库、重建索引；建立资料清单、环境 ID 映射及召回验证流程。

## Capabilities

### New Capabilities

- `standalone-delivery`: 独立应用、访问控制、知识初始化及离线交付的可验证契约。

### Modified Capabilities

无；本仓库尚无既有规格。

## Impact

源项目的分包前后端、共享解析、模型、会话和知识服务依赖需审计并适配；客户环境部署、真实业务数据、知识资料授权和验收均不由本提案隐含授权。
