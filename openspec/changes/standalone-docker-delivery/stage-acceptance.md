## 剩余推进顺序

1. 根据用户对 PyMuPDF 处理方式的选择，核对或重新构建对应版本，补足来源及许可证证据；若镜像变化，重新生成 SBOM、归档并复验。
2. 根据用户对扫描资料定位方案的选择，在隔离环境验证可靠页码；不能据 OCR 片段猜测页码。专家另行确认条款适用性、原文视觉定位和报告质量。
3. 核对其他未知初始化操作的人工处理说明，以及全部关键依赖的许可、对应源码和声明；不能将自动扫描未识别项视为自动通过。
4. 获取客户目标主机规格、网络与 HTTPS 入口、备份位置和运维责任人；在明确授权及实际目标后执行部署和客户验收。

真实业务材料、专家结论与客户部署是独立验收项；未经相应证据不能写为已完成。源知识服务不修改、不重启；正式凭据不得放入 Git、镜像、测试日志或聊天。
