# 38 条专家意见与独立版范围交叉表（阶段 2 草案）

## 使用口径

来源为广场版 `openspec/changes/bs-expert-review-boundaries-20261110/acceptance-matrix.md` 及 `design.md`。该矩阵明确“待讨论、待逐项验证”；本表只把其中明确记录的用户决定标为“已确认”。

- **已确认**：来源有明确的用户决定记录。只代表业务边界已定，不代表独立版已实现、真实材料已验证或专家已验收。
- **待确认**：仍有适用条件、证据标准、材料格式或业务决策未定。已确认的子边界单独写明，不据此扩大实现。
- **不适用**：原意见只是历史样例中的单个字段/日期事实，不是可移植的产品规则；通用核查能力仍可能适用。
- 仅把可移植的分包业务语义列入独立版候选；平台宿主、身份、计费、其他智能体及单个任务事实不作为独立版需求。

## 阶段 2 的建议顺序

该顺序只用于审阅和建立工作包；实现范围须由用户确认后冻结。

1. **范围、执行与报告门禁**：第 4、21、24、25 项。先核实未匹配、可能匹配、运行失败/未完成、读取缺口及正式报告 readiness 是否分开。
2. **签署与人员证据**：第 5、13、37、38 项；补充检查第 1、6、25 项的逐人/逐侧证据关联。
3. **证照、日期和材料质量**：第 9–15、21–26 项；对缺少权威适用依据者保持待确认，不凭样例补规则。
4. **合同范围和分包关系**：第 2–3、27–36 项；只按已确认的材料范围/证据门实施，地域性例外单独审批。
5. 第 1、7–12、14、22–23、26、29、32 项保持待确认队列；第 16–20 项不迁移单次样例事实。第 9/10 项的有限日期识别实现不等于完整业务边界冻结。
