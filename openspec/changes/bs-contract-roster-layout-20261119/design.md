# 设计

仅对sub/labor中独立标题“分包人主要项目管理人员表”与显式姓名/岗位或名称列头启用。沿用现有结构化OCR产物的文本行，仅新增有限岗位/姓名/资格行语法，支持岗位姓名被合成同块且后附明确资格词的行，无法唯一分割不猜；不改既有需要电话的独立报审名单布局解析器。独立总部/现场分区只保留现场记录；未带这类分区时正常提取声明。

复用extract_management_roster及contract_roster_evidence，evidence_kind固定contract_roster，新增字段为声明来源，不能视为实际证书。无电话不代表没有人员；没有足够行结构时仍保持待核实。重复声明可分别保留证据，逐人主键沿用既有主体/身份证优先逻辑。

验证用匿名合成形状回归，不把真实人员信息固化到正式测试。隔离真实快照仅作文本/布局覆盖回放；不得修改源数据库、旧事实、任务或报告，也不执行OCR或付费调用。
