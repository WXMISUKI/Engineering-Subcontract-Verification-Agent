## ADDED Requirements

### Requirement: 独立合同人员声明按同行结构提取
系统 MUST 在独立人员表标题和明确列头约束下提取无电话合同人员声明，保留姓名、岗位、同行资格声明及原始页来源；无法唯一分割的行不得猜测。

#### Scenario: 岗位姓名紧连
- **WHEN** 独立人员表中明确岗位、姓名与资格边界且无联系电话
- **THEN** 保存该行合同人员声明，不因缺电话将整张名单当作没有人员

#### Scenario: 总部与现场分区
- **WHEN** 同表分总部和现场人员
- **THEN** 总部人员不得自动贡献现场岗位齐套或人数

### Requirement: 合同声明不能替代实际证明
系统 MUST 保持声明与证件/劳动/社保事实分离，不能从声明职称或资格推断已提供对应证件。

#### Scenario: 合同人员表写二级建造师
- **WHEN** 仅有合同人员声明二级建造师
- **THEN** 展示声明及来源，但实际资格、劳动合同、社保仍按独立证据核对

#### Scenario: 隔离回放
- **WHEN** 用真实任务已有解析文本验证新布局
- **THEN** 不修改源任务或历史报告，不声称已经重新OCR或完成真实业务验收
