## Context

真实材料第 22 页管理人员名单和第 28 页证书记载的项目经理交安 B 证编号不同。当前编号核查依赖布局坐标，名单表格文字可被既有人员提取器读取却没有接入编号核查。页面级识别质量提示可能包含与具体项目无关的页面。

## Decisions

1. 首期验证名单与证书的证据链，以及企业负责人材料提示；再推广其余人员要素。保留原始文本和页码，比较时只规范化空格、括号及字符宽度，不能猜测数字。
2. 名单字段必须有可信同行关系；单凭同名不保证身份唯一。不能确认关系时给出候选来源并保持不可判定。质量存疑的页不自动判定冲突。
3. 每项问题应包含对象、字段、具体原因和可用来源；不把全文件的质量页列表拼进每一条业务问题。没有依据时如实说明，不猜测模糊或证据缺失。
4. 文件/页、文本片段和有效坐标为独立定位等级；只有坐标经校验和转换才能高亮。模型结果不是原件的证明。
5. 沿用当前线上 OCR 和模型，首次识别后质量可疑或字段无法确认的页面直接作为人工复核线索，不自动重复识别或旋转补读；不把质量可疑等同于已证实模糊、遮挡或缺件。保留原结果、页码和人工意见，不自动重跑旧任务或修改原知识库。
6. 证据存储复用现有能力优先；如需新字段或迁移，先验证兼容性并更新设计。不同用户和主体的证据不能混用。

## Verification

以原始 PDF 建立人工基准；覆盖同号、不同号、同名歧义、跨主体、无证据、模糊页和多行表格等反例。分别验收规则结果、引用页、PDF 可视定位、人工复核和报告；真实任务以隔离新任务进行。不能把测试通过等同于原件业务正确。
