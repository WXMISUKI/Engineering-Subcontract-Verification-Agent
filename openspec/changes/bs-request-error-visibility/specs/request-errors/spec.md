## ADDED Requirements

### Requirement: 模型请求异常真实可见
系统 SHALL 对材料 OCR 与 AI 辅助核查的可确认请求异常按阶段记录脱敏类别，并通过任务事件展示；不得从超时推断 HTTP 429，不得输出凭据或材料正文。

#### Scenario: OCR 页面限流
- **WHEN** 线上 OCR 对某一页明确返回 HTTP 429
- **THEN** 对应页面保持未读取，任务时间线提示材料识别受限和可信页码，不得虚构缺件或符合结论

#### Scenario: AI 批次限流
- **WHEN** AI 核查批次明确收到 HTTP 429 且未完成
- **THEN** 时间线说明 AI 核查受限、批次和可行操作，已完成结果及原有人工意见不变

#### Scenario: 其他请求失败
- **WHEN** 请求超时、认证失败或其他错误
- **THEN** 展示对应类别或安全的通用错误，不将其标记为 429

#### Scenario: 质量存疑页面
- **WHEN** 首次 OCR 已返回但页面内容质量存疑
- **THEN** 直接交由人工核对，不自动反复识别或旋转补读
