## Goals / Non-Goals

**Goals:** 基于可追溯事实自动形成十项基本信息、五类业务摘要、待处理事项及结论；同一报告内容供页面、Word、PDF 使用；异常可在现有工作台定位，避免逐项重复确认。

### 现有规则映射与限制（2026-11-10 代码核对）

- 要素完整性依据 `data/report_checklist.json` 的固定条目映射：RC-08 为报审资料，RC-A01 为合同及清单，RC-A02 至 RC-A06 为主体资料，RC-A07 至 RC-A09 及 RC-P/RC-L 现有人员条目为人员资料，RC-A10 和 RC-09 为签字盖章及审批资料。未识别编号不强行分类，需关注的结论仍进入问题清单。完整性规则的 `miss` 只表示相应资料查见，不能表述为实体资质或内容已符合。
- 人员一致性当前 A2-01 核查社保资料对名单的覆盖，并单独保留劳动关系及本单位社保关系尚未证明的限制；不能据此推断所有岗位、证件或特殊工种均已核实。
- 人员摘要可引用完整性清单 RC-A09（主要管理人员名单）、RC-P16/RC-L14（特殊工种名单及操作证资料）和 A2-05（项目经理交安 B 证编号对应）。完整性结果只描述资料查见或待关注，不代替人员任职、证件有效性和劳动关系核验；忽略回执同样适用，原规则归属及问题清单不因摘要引用而改变。
- 证件有效期 A2-02 的报告展示标签统一为“证件有效期”，其中正向结果可聚合多条证照记录；现有投影没有稳定的企业/个人证件类型字段。无法可靠归类时不凭通用标签、相邻页或猜测将其填入某一固定字段，问题仍须保留。后续如需细分，须先在核查结果中建立有来源的类型与聚合边界，并覆盖历史快照兼容。
- A2-03 是证件注册单位一致性，A2-05 是项目经理交安 B 证编号一致性；两者可归入证件信息一致性，不能当作证照真实性核验。
- `hit` 也包含证件临近到期等预警，类别汇总使用“需关注”，`undecidable` 使用“待核实”，不能将所有 `hit` 概括成“不符合”。

**Non-Goals:** 不新增报告正文编辑器，不以报告展示替代法规核查；不引入设备、资金、质量安全进度等新核查范围；不放宽门禁、部署或写入目标环境。

## Decisions

1. 报告专用只读投影：聚合当前代次的任务锚点、有效材料、事实、finding、人工处置和覆盖情况；保留现有机器审计结构和历史输入的兼容路径。相较直接修改核查内核，此方式降低规则指纹和既有判定变化。
2. 实体字段优先复用既有 OCR 页文本和版面，处理明确角色标签及清单标题边界，记录候选值和来源；明确来源冲突不选择第一个值。规则不能可靠覆盖的关键页可采用受约束模型辅助，必须保留来源并校验结果；未证明必要前不新增调用或费用。甲乙方依合同角色解释；收件人不普遍视为建设单位。
3. 五类业务字段按实际结构化核查和适用性映射，结果不足或运行不完整须明确；不将自由文本截断或无项结果解释为通过。报告主表排除人工忽略事项，审计数据及授权回溯导出保留，状态与决定分别表达。
4. 展示四部分，采用已确认字段；正文精简而不丢失未决事项，输出避免虚构责任人、期限或管理决定。Word、PDF、页面消费相同语义投影，各自适配排版，保持初稿与确认稿及门禁。
5. 版本保持现有快照为准：新字段必须可由所引用的冻结材料与结果重建或被快照保存，历史版本不得误读当前材料；对旧快照缺失字段明确降级。具体机制先验证现有代码，避免先行数据库迁移。

6. AI 辅助核查的任务级材料输入遵循证据锚点：finding 已登记材料/页锚点时只传入锚点页及相邻页，并在模型上下文和报告限制中标明范围不完整；没有锚点时保持现有全量选择和 fail-closed 语义。该裁剪只降低请求规模，不改变规则 finding、引用授权或正式结论。

## Risks / Trade-offs

- [OCR 表格错列、截断或事实跨页] → 保持页码及原文、检查标题边界，不能可靠确定时保留未决；使用扫描真实样本和冲突反例。
- [误把项目公司、报审收件人或分包甲方视为业主/总包] → 按文档角色及明确标签解析，冲突保留，不按名称推断。
- [摘要遗漏问题或把缺件与无法核实混淆] → 验证输入集合、人工回执、覆盖状态及可追溯映射，不以项数或空列表证明通过。
- [快照混入新材料及忽略项泄露] → 当前、历史、Word、PDF、预览和审计导出分别验证，保持权限与门禁。
- [样本版式与可用渲染工具不兼容] → 输出和模板进行视觉核对；无法渲染时如实记录，不宣称版式验收通过。

## Migration Plan

本地分阶段实现并测试，保持旧结构的兼容读取；不迁移历史任务或生产数据。需要持久化 schema、扩大模型调用、部署或变更规则判定时先具体评估并依照用户决策执行。回退通过撤销本变更投影与导出接线，既有结果和快照保留。
