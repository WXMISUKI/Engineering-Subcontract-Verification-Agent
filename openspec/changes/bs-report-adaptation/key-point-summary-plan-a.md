# 关键点摘要报告方案 A

## 目标和范围

报告保留五阶段关键点表格，将普通未处理问题及已采纳的人工补充归入相应要点，忽略事项不进入正文。移除独立待处理事项摘要和报告末尾校验码、导出时间。页面、Word、PDF 使用相同口径。

## 约束

- 保留现有确认稿阻断门禁、历史快照、证据包和审计记录；默认展示系统意见不写入人工采纳状态。
- 摘要依据现有核查结果及真实人工备注，不能将证据不足表述为符合；对无法映射的事项提供可见归属，避免删除章节后遗漏。
- 同一关键点合并重复信息，不丢弃不同事实；人工备注只在有内容时展示，避免重复与空章节。
- 内部数据结构可继续提供原始事项及存证字段，展示调整不改变原始数据。
- 表格展示“审查要点及主要依据／核查情况／判定”；依据仅展示与该要点实际关联的已保存来源，不能将步骤级依据冒充单项依据。
- 判定分符合、基本符合、不符合、待核实；只有现有证据和明确规则能够支持时才能给出确定判定。命中、严重度低和人工采纳不等于基本符合；无法区分预警与不符合时为待核实。未开展、未完成、无结果或证据不足不得显示符合。该展示不改变门禁与原始状态。
- 若当前规则没有明确区分轻微不符合或确定违规的结构化判据，保守展示待核实，不以关键词臆造四态；以后可补充经过确认的规则映射。
- 现阶段明确映射：在核查完成、读取完整且存在来源时，报审资料清单 RC-A03 的明确缺失代表主体资料不符合；证照在基准日仍有效但临近到期，即使该要点其他检查均符合，按用户确认的口径仍显示待核实。低严重度不得自动转为基本符合。

## 阶段及验收

1. 检查现有报告及门禁规则，建立本方案。
2. 按关键点生成问题与人工补充摘要，检查未处理、采纳、忽略、重复和未映射问题。
3. 调整预览与 Word/PDF 输出，去掉指定章节及报告末尾校验信息。
4. 针对性验证门禁、历史快照、三种输出及中文 PDF，生成标明稿别的示例报告。
