# 设计

- 复用人员共同抽取层，以实际独立证明标题为入口；条款、清单、模板和提交义务不能代替证明。各证明段/人员记录保留材料、页码、引文、主体和身份证候选。工资/退休/返聘/到岗/业主允许均为证据候选，不因关键词验真。
- 分公司以同主体的登记证明及隶属关系证明，明确同一分公司名称和上级法人。仅名称包含母公司不再自动认定。缺任一证明=缺项；冲突=待核实。子公司/上级公司/人力资源/个人不按分公司放行。
- 退休证明确的人不按普通社保缺失流程放行。关键四岗（项目/技术/质量/安全）需补报符合口径的人员；非关键已知岗位须退休证、返聘协议、到岗承诺、业主书面允许四类候选。缺证=缺项；齐备=待核实，复用人工复核确认实际书面允许、签章和适用条件。岗位不明不猜非关键。
- 工资记录附加单位/期间和来源说明。缺失或单位差异均不单独改变人员判定，不成为新的附条件通过原因。
- 对齐规则数据中退休key_posts与已确认notes的矛盾；版本递增并保持范围不完整标记，不重写历史。
