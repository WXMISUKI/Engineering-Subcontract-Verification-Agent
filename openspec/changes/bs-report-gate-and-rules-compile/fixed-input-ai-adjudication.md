# AI 判定与固定输入边界

同一核查代的结论指纹和 A1 上游依赖指纹必须反映 AI 判定前的原始结论。AI 判定是该代输出，写入审计记录及机器结论投影不得使自身或下游参考运行失效。材料、规则、授权及原始结论真实变化仍须阻断。

对 AI 会改写的结论字段，记录原始值和本次投影值；仅在当前值与记录的投影一致时还原原始值计算指纹。重复判定沿用原始值。无法证明原始值的旧 hit/miss 判定不得推测恢复；旧 undecidable 判定只写审计字段，可安全按空审计字段计算历史指纹。已保存的参考指纹算法形态保持兼容。

验证覆盖三态、跨组依赖、投影被外部更改、真实输入变化、旧记录及同代重试。不得自动调用真实模型或修改现有任务数据；实际重试须用户主动发起。
