## 2. 实现与验收

- [ ] 2.1 接入准入九维结果和报告投影，保留五步核查流程。
- [ ] 2.2 实现已核实的 SH-FB-04 条件，验证范围通过、负面清单命中、整体发包、证据不足及完整单位工程各分支。
- [ ] 2.3 核对准入页面、报告与原页证据一致，验证倒查问题列表及历史报告兼容。
- [ ] 2.4 复用倒查现有逐条覆盖、候选校验和上下文复核能力，补齐两模式的来源范围、失败原因与复核记录。
- [ ] 2.5 为八类首轮样本建立可定位的预期问题、反例和待核事项。按规则及样本分别核对漏报、误报、证据准确性和无法判断的范围。
- [ ] 2.6 实现两模式共用的报告表述模板，验证单处证据、多处佐证、全文未查见和核查受限的写法；对照受控模型润色，验证事实保留与失败回退。
- [ ] 2.7 实现未完成时的时间线和续跑入口，验收成功检查点复用、失败批次恢复、状态回显及完成后出报告。
- [ ] 2.8 单一准入报告入口复用现有人工复核门禁，验证有待处理项时拦截、全部必须处理项完成后生成。
