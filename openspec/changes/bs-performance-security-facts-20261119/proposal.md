# 履约担保与保险事实候选

## Why
主8.11缺独立保函/保证金凭证与保险单事实，不能用合同承诺代替实际提交，也不能把任意保险单当履约担保。

## What Changes
- 按独立已读附件标题提取履约保函/履约保证金凭证、工程保险单的项目/合同号、编号、当事方、金额/比例和期间候选。
- A3-04-security接签字组及主体门禁，追加security.records和报告提示；三类独立，不跨证明借字段或合并金额。
- 118号第六条首次/重新承揽专业分包等条件及总包同比例尚需业务确认；候选不自动适用到劳务或输出符合/不符合。

## Impact
本地独立事实切片，主8.11仍部分。未涵盖真实性、受益人/担保人权限、总包比例对照、工期实际覆盖、首次/重新承揽与保险险种适用性真实验收。不调用Provider/OCR/真实重跑或部署。
