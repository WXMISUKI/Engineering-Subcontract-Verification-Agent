## ADDED Requirements

### Requirement: 担保证明与保险不得相互替代
系统 MUST 分别保存履约保函、履约保证金凭证和保险单的明确字段及原文来源，不跨记录借当事方、金额、期限或编号。

#### Scenario: 保函后附保险单
- **WHEN** 同页保函后出现独立保险单
- **THEN** 两条记录各自保留字段，保费不能作为履约保证金额

#### Scenario: 合同应提供担保
- **WHEN** 只有合同提交义务或空模板
- **THEN** 不生成实际已提交担保证明

### Requirement: 担保候选不能自动触发全类型义务
系统 MUST 保留人工核对适用条件，不据原文金额/有效期自动判符合或不符合，不机械要求劳务分包适用专业分包担保。

#### Scenario: 首次承揽状态未知
- **WHEN** 首次或重新承揽适用性、总包比例或合同工期未确认
- **THEN** 记录只作人工提示，不能视作已验证同比例和全工期有效
