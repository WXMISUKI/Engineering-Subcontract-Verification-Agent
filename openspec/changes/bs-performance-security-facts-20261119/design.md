# 设计与完成条件

复用独立文档标题/已读页与is_attachment_source。保函、保证金凭证、保险单按精确标题及有限正副本后缀切段，保存每个字段候选数组，冲突不选择首值；只解析明确字段行，不从合同约定或附件目录出已提交证明。所有记录保留subject_id/material_id/page/quote/evidence_kind。记录类别不互换：保险不是保函，付款意向不当保证金实缴；原文退回/已失效状态不改为有效。

合同编号/项目和受益人/申请人/担保人/投保人/被保险人按各自字段保留；不按同名项目或空编号自动关联合同。金额/比例及有效期原文只作为待核候选，不计算与合同额的比值、不比较总包比例，不把保费当保额，不把投保期当实际保险责任范围。

服务A3-04-security固定undecidable/manual_prompt，复用signature_chain组及_run_subject_checks；提示说明专业分包首次/重新承揽适用性、总包同比例、分包工期和原件需人工核实，劳务不被自动要求提交同种担保。事实security.records独立追加，旧批次保留；通用证据/报告人工提示可定位。

完成条件：三种记录类别隔离、多值/否定保留、同页后继文档切断、模板/目录/合同义务/未读排除、SQLite重复运行/旧批次/主体门禁、报告不改变签署结论；规则版本与规格校验、源码身份和验收记录清楚。
